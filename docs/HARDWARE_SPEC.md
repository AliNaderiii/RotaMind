### ۴. مشخصات سیگنال (تایید مهندس مکانیک)

**چرا ۱۲.۸ kHz؟**
- طبق استاندارد ISO 10816-3، عیوب بلبرینگ تا ۵kHz هستند.
- Nyquist می‌گوید fs > 2*5kHz = 10kHz. ما ۱۲.۸kHz گرفتیم تا عدد توان ۲ باشد (برای FFT سریع).
- فرکانس‌های عیب قابل تشخیص:

```
BPFO = (n/2) * RPM/60 * (1 - d/D * cosα)
BPFI = (n/2) * RPM/60 * (1 + d/D * cosα)
BSF  = (D/2d) * RPM/60 * (1 - (d/D cosα)^2)
FTF  = (1/2) * RPM/60 * (1 - d/D cosα)

مثال: بلبرینگ 6205, RPM=1800, n=9, d=7.9mm, D=39mm
→ BPFO=87Hz, BPFI=133Hz, BSF=58Hz
→ با fs=12.8kHz، تا هارمونیک ۵۰ام را می‌بینیم
```

**چرا ±16g؟**
- ارتعاش معمول بلبرینگ سالم: 0.1-0.5g RMS
- بلبرینگ معیوب شدید: 3-8g Peak
- شوک 2000g enDAQ برای تست سقوط موشک است، برای کارخانه لازم نیست. ADXL345 با 16g و نویز 0.04g RMS کافی است.

### ۵. فریمور — منطق کاری

**حالت‌ها (با یک دکمه):**
1. **Idle:** LED سبز چشمک‌زن، مصرف 10mA
2. **Recording:** دکمه ۱ ثانیه → LED قرمز ثابت → ضبط 12.8kHz به `DATA_YYYYMMDD_HHMMSS.CSV` → دکمه دوباره → توقف
3. **USB Transfer:** وصل به لپ‌تاپ → به عنوان Mass Storage شناخته می‌شود → فایل‌ها را درگ کنید (مثل فلش)

**فایل خروجی CSV:**
```
timestamp_ms, ax_g, ay_g, az_g, temp_c, rpm_est
0, 0.12, -0.03, 1.01, 42.3, 1798
0.078, 0.15, -0.02, 0.98, 42.3, 1798
...
```
- فرمت ساده، قابل باز شدن در RotaLab, Excel, MATLAB
- هر ۱۰ ثانیه = ~1.5MB (3 کاناله, Float32)

**کد فریمور:** `hardware/firmware/esp32_firmware.ino` (آردوینو، قابل فهم برای تکنسین)

### ۶. قاب (CAD)

- **جنس:** آلومینیوم 6061 آنودایز شده (یا برای MVP پرینت سه‌بعدی PETG)
- **ابعاد:** 60×40×22mm — کمی بزرگتر از enDAQ (50×30×12mm) ولی قابل حمل در جیب
- **آب‌بندی:** IP54 (پاشش آب، نه غوطه‌وری) — با واشر سیلیکونی
- **فایل:** `hardware/cad/enclosure.step` + `enclosure.stl`

**دستور پرینت:**
```
Perimeters: 4, Infill: 60% Gyroid, Material: PETG, Nozzle: 0.4mm
زمان پرینت: ~2.5 ساعت
```

### ۷. تست و کالیبراسیون

**تست کارخانه‌ای (قبل از تحویل به مشتری):**
1. تست شیکر: 1g @ 100Hz → خروجی باید 0.95-1.05g باشد
2. تست دما: 25°C → 24-26°C
3. تست SD: نوشتن 100MB بدون خطا

**کالیبراسیون کاربر:** نیازی نیست — ADXL345 کارخانه کالیبره است. فقط قبل از نصب، ۵ ثانیه روی میز ثابت بگذارید تا بایاس صفر شود (دکمه ۵ ثانیه نگه دارید).
