# USER GUIDE — راهنمای کاربر RotaLab v1.0
## نرم‌افزار آفلاین پایش ارتعاش

**برای: مهندس نت، تکنسین — بدون نیاز به دانش AI | زبان: فارسی + انگلیسی**

---

### ۱. نصب (۳۰ ثانیه)

1. فایل `RotaLab-Portable-v1.0.exe` را از فلش/سایت کپی کنید.
2. دوبار کلیک — نیاز به نصب ندارد!
3. برای میانبر: کلیک راست → Send to Desktop

> **سیستم مورد نیاز:** ویندوز ۱۰/۱۱ (۶۴ بیتی)، ۴GB RAM، 500MB فضا. بدون نیاز به اینترنت.

---

### ۲. اتصال سنسور RotaTag

**روش A: با کابل USB (پیشنهادی فاز ۱)**
1. RotaTag را روی موتور با مگنت بچسبانید (نزدیک یاتاقان، جهت عمودی).
2. کابل USB-C را به لپ‌تاپ وصل کنید.
3. در RotaLab، دکمه **"خواندن از سنسور"** → فایل `DATA001.CSV` خودکار لود می‌شود.

**روش B: با کارت حافظه**
1. کارت microSD را از RotaTag خارج کنید (سوزن داخل جعبه).
2. به لپ‌تاپ بزنید، فایل CSV را درگ کنید داخل RotaLab.

### ۴. کار با نرم‌افزار — گام به گام

#### گام ۱: فایل را باز کنید
- فایل CSV/TDMS/MAT را بکشید و رها کنید (Drag & Drop).
- یا: File → Open

#### گام ۲: سیگنال را ببینید
- **زوم:** چرخ موس
- **حرکت:** کلیک و درگ
- **Fit:** دکمه Fit تا همه سیگنال جا شود
- **کانال:** تیک ax/ay/az را بزنید/بردارید

#### گام ۳: فیلتر بزنید (اختیاری)
- منوی Filter: `Envelope (پیشنهادی)` را انتخاب کنید.
- برای نویز برق: `Notch 50Hz`
- برای نویز فرکانس پایین: `Highpass 10Hz`

#### گام ۴: تحلیل هوشمند — مهم‌ترین بخش
1. دکمه **🔍 تحلیل هوشمند** را بزنید.
2. ۲-۳ ثانیه صبر کنید (نوار پیشرفت).
3. نتیجه را ببینید:

**مثال ۱ — سالم:**
```
🟢 سالم — اطمینان 94%
RMS: 0.18g, Peak: 0.45g
توصیه: وضعیت عالی — پایش ماهانه کافی است.
```

**مثال ۲ — عیب Outer:**
```
🔴 عیب Outer Race — اطمینان 97% — شدت متوسط
فرکانس عیب: BPFO = 87.3 Hz (هارمونیک 1x, 2x, 3x دیده شد)
طیف Envelope: قله در 87Hz و 174Hz
توصیه: برنامه‌ریزی تعویض در 2-3 هفته آینده. روغن‌کاری را چک کنید.
```

#### گام ۵: گزارش PDF بگیرید
- دکمه **📄 PDF** → محل ذخیره را انتخاب کنید.
- فایل شامل: لوگو، تاریخ شمسی، نمودارها، نتیجه AI، توصیه فارسی.

### ۵. تفسیر نتایج — راهنمای سریع

| رنگ | معنی | اقدام |
| :--- | :--- | :--- |
| 🟢 سبز | سالم | پایش ماهانه |
| 🟡 زرد | هشدار اولیه (Early) | پایش هفتگی + چک روغن/نصب |
| 🟠 نارنجی | متوسط | برنامه‌ریزی تعویض در 1 ماه |
| 🔴 قرمز | شدید (Critical) | توقف و تعویض فوری — خطر شکست |

**نکته:** همیشه **طیف** را کنار نتیجه AI ببینید. اگر AI گفت "Outer" ولی در طیف قله‌ای روی BPFO نبود، با ما تماس بگیرید — ممکن است نویز باشد.

### ۶. عیب‌یابی

| مشکل | راه‌حل |
| :--- | :--- |
| فایل باز نمی‌شود | مطمئن شوید CSV هدر دارد: `timestamp,ax,ay,az,temp` |
| نمودار خالی است | دکمه Fit را بزنید، یا Time را از 10s به 1s تغییر دهید |
| تحلیل هوشمند کار نمی‌کند | مطمئن شوید فایل حداقل 2 ثانیه (25600 نمونه) دارد |
| نتیجه "نامطمئن" | سیگنال خیلی نویزی است — سنسور را محکم‌تر بچسبانید، یا فیلتر Envelope بزنید |
